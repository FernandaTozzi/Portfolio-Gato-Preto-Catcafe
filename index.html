Sobre o projeto

Proposta e Objetivo

O projeto de estágio tem como objetivo desenvolver um website para o Cat Café Gato Preto, divulgando o estabelecimento, seus serviços e sua proposta, além de proporcionar uma melhor experiência de interação entre o público e o espaço.

A plataforma apresenta informações sobre a cafeteria, gatos disponíveis para adoção, cardápio e atividades especiais, além de oferecer recursos de contato e outras funcionalidades relacionadas ao atendimento dos clientes.

O projeto também busca fortalecer a presença digital do estabelecimento, ampliar sua visibilidade e aplicar, na prática, conhecimentos de Engenharia de Software, especialmente em desenvolvimento de interfaces, UI/UX, levantamento de requisitos, prototipação, implementação e testes.

01

Problema que o sistema busca resolver

A ausência de uma presença digital estruturada pode limitar a visibilidade do Cat Café e dificultar a comunicação com o público. O sistema busca centralizar as principais informações do estabelecimento e facilitar o acesso dos clientes aos serviços, gatos disponíveis para adoção, cardápio, atividades e formas de contato.

02

Tecnologias utilizadas

Conforme o planejamento do estágio, o desenvolvimento utiliza React Native 0.73, HTML5, CSS3, JavaScript ES2025 e TypeScript 5.9. Para armazenamento dos dados, o projeto utiliza MySQL 8.4.

03

Arquitetura e solução

A solução foi planejada como uma aplicação web responsiva, compatível com dispositivos desktop e mobile. O website organiza em uma única interface as informações institucionais e as funcionalidades de consulta e gerenciamento, utilizando banco de dados MySQL para persistência das informações.

Gerenciar Gatos para Adoção

Permite cadastrar, visualizar e editar os itens do cardápio, incluindo suas informações e preço.

Gerenciar Atividades Especiais

Permite cadastrar, visualizar e editar atividades e eventos especiais, com informações como foto, horário e detalhes.

Alterar Conta de Doações

Permite atualizar os dados da conta utilizada para o recebimento de doações.

Visualizar Gatos para Adoção
